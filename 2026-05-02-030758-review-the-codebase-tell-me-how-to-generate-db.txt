⏺ I have enough to give you a full walkthrough. Here's how to set up and run
  DebtMate:

  ---
  1. Create a Telegram Bot

  Go to @BotFather on Telegram:
  1. Send /newbot
  2. Follow prompts → get your BOT_TOKEN and BOT_USERNAME

  ---
  2. Configure Environment

  cp .env.example .env

  Then fill in .env:
  DATABASE_URL="postgresql://user:password@localhost:5432/debtmate"
  BOT_TOKEN="<token from BotFather>"
  BOT_USERNAME="<your_bot_username>"
  PORT=3000

  You need a running PostgreSQL instance. If you have Docker:
  docker run -d --name debtmate-pg -e POSTGRES_USER=user -e
  POSTGRES_PASSWORD=password -e POSTGRES_DB=debtmate -p 5432:5432 postgres

  ---
  3. Generate the Database

  # Run migrations and apply schema (creates tables)
  pnpm db:migrate

  # Then generate the Prisma client
  pnpm db:generate

  Or for a quick push without migration history:
  pnpm db:push

  The schema has 3 tables: User, Relationship, and Transaction.

  ---
  4. Build

  pnpm build        # compiles TypeScript → dist/

  ---
  5. Run

  Development (hot-reload, long-polling):
  pnpm dev

  Production (requires WEBHOOK_URL in .env):
  pnpm start        # runs dist/index.js

  In dev mode the bot polls Telegram automatically — no webhook needed.

  ---
  6. Using the Bot

  Open your bot in Telegram and use these commands:

  ┌───────────┬───────────────────────────────────────────────────┐
  │  Command  │                   What it does                    │
  ├───────────┼───────────────────────────────────────────────────┤
  │ /start    │ Register your account                             │
  ├───────────┼───────────────────────────────────────────────────┤
  │ /invite   │ Get a personal invite link to share with a friend │
  ├───────────┼───────────────────────────────────────────────────┤
  │ /contacts │ View all connected contacts and their balances    │
  ├───────────┼───────────────────────────────────────────────────┤
  │ /balance  │ Check balance with the currently selected contact │
  ├───────────┼───────────────────────────────────────────────────┤
  │ /add      │ Start a guided flow to record a debt or loan      │
  ├───────────┼───────────────────────────────────────────────────┤
  │ /logs     │ View recent transactions with the active contact  │
  ├───────────┼───────────────────────────────────────────────────┤
  │ /help     │ Show help                                         │
  └───────────┴───────────────────────────────────────────────────┘

  Typical flow:
  1. /start — registers you in the DB
  2. /invite — get your link, share it with a friend
  3. Friend clicks the link → both are auto-connected
  4. /contacts → select the friend
  5. /add → choose DEBT or LOAN, enter amount (and optional note)
  6. /balance to see the running total
